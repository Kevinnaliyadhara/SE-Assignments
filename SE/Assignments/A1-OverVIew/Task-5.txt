Ans-1: 

1. Initialize a repository: git init
2. Stage all files: git add .
3. Commit with a message: git commit -m "Initial commit"
4. Push to remote: git push origin main
5. Pull the latest changes: git pull origin main

Ans-2:

git fetch downloads the latest changes from the remote repository without merging them into the current branch.
git pull downloads the latest changes and integrates them into the current branch.

Ans-4: 

A Fork creates a copy of someone else's repository under your GitHub account so you can work on it independently.
A Pull Request (PR) is a request to review and merge your changes into another branch or repository.
